# DSP-Lab Main-Study Data Collection Order

This file gives the exact minimum collection order for the current publication design.

1. Assign coded participant IDs and final group labels.
2. Administer Form A pre-test to both groups.
3. Run Week 1 Signals activities and complete the fidelity log.
4. Run Week 2 Sampling activities and complete the fidelity log.
5. Run Week 3 Convolution activities and complete the fidelity log.
6. Run Week 4 DFT activities and complete the fidelity log.
7. Run Week 5 FIR activities and complete the fidelity log.
8. Administer Form B post-test to both groups.
9. Administer the student-experience questionnaire to the experimental group.
10. Export coded DSP-Lab CSV files from the experimental group.
11. Enter group labels and control-group scores in `study_metadata.csv`.
12. Archive raw exports unchanged.
13. Run the synthetic smoke test before the real analysis.
14. Run the prespecified main analysis.
15. Fill the CAE Results section from the generated output files.

Do not add new primary outcomes after Step 8 because of observed results. If a procedural deviation occurs, record it rather than silently changing the sequence.
