# Control-Group Conventional Review Package

This folder contains five conventional after-class review activities designed for the control condition of the DSP-Lab teaching study.

## Purpose

The control condition should receive learning support that is comparable in topic coverage and approximate study time to the DSP-Lab condition, while omitting the defining features of the mobile intervention: interactive parameter manipulation, immediate plot updates, app-based guided exploration, automatic timing, and app reflection capture.

The goal is therefore to compare **mobile interactive self-learning** with **conventional structured review**, not additional learning versus no learning.

## Standard format

Each review activity is intended to require approximately 15–30 minutes and contains:

1. a concise concept summary;
2. one worked example;
3. several written practice questions;
4. one short compare/explain task;
5. one short written summary prompt.

Students should complete the activities independently after the corresponding topic has been taught in class.

## Files

- `LAB01_SIGNALS_REVIEW.md` — discrete-time signals
- `LAB02_SAMPLING_REVIEW.md` — sampling and aliasing
- `LAB03_CONVOLUTION_REVIEW.md` — discrete convolution
- `LAB04_DFT_REVIEW.md` — DFT and spectrum
- `LAB05_FIR_REVIEW.md` — FIR low-pass filtering
- `INSTRUCTOR_KEY.md` — suggested answers and implementation notes

## Standardization rules

For the main study:

- use the same version of each worksheet for all control participants;
- distribute each worksheet only after the corresponding lecture topic;
- do not add extra instructor explanations to one group only;
- do not show the DSP-Lab interface or screenshots to the control group during the intervention period;
- do not use exact Form A/Form B test wording in the worksheets;
- where feasible, ask control students to record approximate start/end time or self-reported minutes spent;
- collect completion evidence in a consistent way if the protocol requires it.

The written summary prompt is included to give the control condition a modest generative-learning component without reproducing the DSP-Lab interaction itself.
