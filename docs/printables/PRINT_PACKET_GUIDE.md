# DSP-Lab Classroom Print Packet

This folder contains clean student-facing materials for the teaching study. The print packet is intentionally simple so that the study can be implemented without adding extra research procedures.

## Files

- `FORM_A_PRINT.md` — 12-item Form A concept test for the pre-test.
- `FORM_B_PRINT.md` — 12-item Form B concept test for the post-test.
- `ANSWER_SHEET_PRINT.md` — reusable 12-item answer sheet.
- `QUESTIONNAIRE_PRINT.md` — 10-item DSP-Lab student experience questionnaire for the Experimental group after Form B.

## Administration

### Main study

1. Give both groups Form A before the five-week learning period.
2. Use the same time allowance and calculator policy for both groups.
3. Do not provide item-by-item feedback before the intervention is complete.
4. After the five-week period, give both groups Form B under comparable conditions.
5. After Form B, give the questionnaire only to the Experimental group that used DSP-Lab.

### Pilot

For the AB/BA pilot, use the same Form A and Form B print files, but follow `docs/PILOT_ADMINISTRATOR_RUN_SHEET.md` rather than the main-study order.

## Participant code

Use only the coded participant identifier, for example `S023` in the main study or `P07` in the pilot. Do not write names, student numbers, email addresses, or other direct identifiers on the research forms unless an approved institutional procedure requires a separate administrative record.

## Printing

- Paper: A4, portrait.
- Print at 100% scale.
- Do not print answer keys together with student copies.
- Keep completed forms in a secure location until data entry and archiving are complete.

## Version control

The wording in these files mirrors the frozen item wording in `LearningAssessment.kt` and the 10 questionnaire items in `docs/STUDENT_QUESTIONNAIRE.md`. If any item must be changed before the main study, update the app/instrument source and print version together, document the change, and freeze the revised version before the first main-study pre-test.
