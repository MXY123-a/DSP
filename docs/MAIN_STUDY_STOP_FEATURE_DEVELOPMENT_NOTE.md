# Stop Feature Development Note

For the present CAE manuscript, additional participant-facing DSP-Lab features are not part of the planned contribution. The study now has the required intervention, matched control, outcome measures, fidelity records, analysis plan, and manuscript pathway.

Until the main study is complete, new app features should be deferred unless they correct a genuine technical problem that prevents the frozen intervention from being delivered as intended.

This reduces the risk of intervention drift, version mismatch, and post hoc redesign during data collection.
