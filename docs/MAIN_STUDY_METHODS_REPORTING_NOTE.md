# Main-Study Methods Reporting Note

Use this note only when converting the completed study into the CAE manuscript. It provides a compact reporting structure and does not add a new analysis.

## Intervention delivery paragraph template

> Both groups received the same regular undergraduate DSP instruction. During the five-week intervention, the experimental group completed one mobile DSP-Lab activity per week, whereas the control group completed a topic-matched conventional after-class review activity. The weekly topics were discrete signals, sampling, convolution, DFT-based spectral interpretation, and FIR filtering. Activities in both conditions were designed for approximately 15–30 min of after-class study. Release windows, deadlines, and reminder procedures were kept comparable across conditions. Intervention delivery, technical problems, schedule changes, and potential cross-condition contamination were recorded prospectively using a weekly fidelity log.

## Assessment paragraph template

> Conceptual understanding was assessed using researcher-developed 12-item parallel concept tests. Form A was administered before the intervention and Form B after the intervention. The forms covered the same five DSP topic domains. Content and parallel-form evidence were evaluated before the main study through expert review and a counterbalanced AB/BA pilot procedure, with detailed diagnostics reported separately.

## Analysis paragraph template

> The prespecified primary outcome was the Form B post-test score. The primary effectiveness analysis estimated the experimental-versus-control difference in post-test score while adjusting for Form A pre-test score using a linear model with Control as the reference group and HC3 robust standard errors. The adjusted group coefficient, 95% confidence interval, and p value were reported as the principal inferential result. Pre/post changes, raw gain, normalized gain, questionnaire responses, completion, and app activity measures were treated as secondary or exploratory evidence.

## Fidelity reporting after data collection

After the study, report only observed facts, for example:

- number of weekly activities delivered as planned;
- any major technical or scheduling deviations;
- evidence of contamination/crossover, if observed;
- completion counts by week and group;
- whether the intended reminder policy was followed.

Do not write statements such as “fidelity was high” unless the completed records support that conclusion.

## Quasi-experimental limitation

If intact classes are used and only one class is assigned to each condition, include a direct limitation statement:

> Because condition assignment coincided with intact class membership, class-level differences cannot be fully separated from the intervention effect; the adjusted analysis reduces baseline imbalance but does not eliminate this design limitation.

This limitation should not be hidden or reframed as random individual assignment.
