# Main-Study Minimum Data Fields

The current CAE paper can be completed with the following minimum data. Do not add variables simply because they are easy to collect.

## Required for primary effectiveness analysis

- ParticipantCode
- Group (`Experimental` or `Control`)
- PreScore (Form A, 0–12)
- PostScore (Form B, 0–12)

## Required for study flow and fidelity reporting

- weekly completion counts by group
- post-test completion counts by group
- documented major deviations/technical issues

## Experimental-group secondary data

- Q1–Q10 questionnaire responses
- five lab completion indicators
- five app elapsed durations
- latest reflection per lab

## Optional/exploratory only

- reflection rubric totals
- engagement correlations
- normalized gain

Names, student IDs, emails, phone numbers, and other direct identifiers are not required for the research analysis dataset.
